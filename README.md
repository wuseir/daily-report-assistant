# 项目日报助手 v1.0.0

将 `daily-report-assistant.user.js` 安装到浏览器用户脚本管理器后，网站右下角会出现“日报助手”。使用者无需安装 Codex、配置 Python、运行命令或获得你的登录信息。

## 安装与分发

1. 在自己使用的 Chrome / Edge / Tabbit 中安装 [Tampermonkey 官方扩展](https://www.tampermonkey.net/)。若公司浏览器禁止扩展安装，先使用公司允许的安装方式。
2. 点击 Tampermonkey 图标 → “添加新脚本 / Create a new script”。删除编辑器中的示例代码，将 `daily-report-assistant.user.js` 的全部内容复制进去，按 `Ctrl+S` 保存。
3. 使用**自己的账号**登录 [项目管理平台](https://projgrg.grgbanking.com/)，刷新页面。在左侧打开“日报填写/审核 → 我的日报”。
4. 点击右下角“日报助手”。若没有按钮，按扩展当前界面的提示检查脚本是否启用及该站点的运行权限；参考 [官方脚本执行权限说明](https://www.tampermonkey.net/faq.php#Q209)。

给同事发送压缩包或 `daily-report-assistant.user.js` 和本文即可。每个人单独安装、使用自己的账号和项目权限；脚本中没有固定的用户 ID、审批人 ID、项目 ID、Cookie 或 Token。

## 每次使用

1. 设置年份、默认工时。无年份的 `10/10` 将按所选年份解析。工时也可在每个日期的预览中单独修改。
2. 导入 UTF-8 编码的 `.md` / `.txt`，或粘贴工作记录，点击“解析内容”。支持 `## 10/10` 分段，以及“日期 | 工作内容”两列表格。示例见 `example.md`。
3. 点击“读取项目”，从当前账号可见的项目中选择。本版本支持“信息化项目待办”里的项目，**并不限制项目**。
4. 审批人默认沿用网站记录 / 项目默认审批人。如需更换，选择“本轮通过网站原有选择器另选审批人”。处理第一条需要编辑的记录时，脚本会打开网站原有选择器并暂停；在网站选好并确定后，重新打开助手，点击“已在网站选好审批人，继续”。同一轮其他草稿使用本轮所选审批人；姓名和 ID 均来自真实选择器，不靠手输姓名匹配。
5. 进入预览，核对日期、项目、工时、文案；取消不需要的日期。所有空白行都会清除，标题和工作项之间只有一个换行。
6. 可先用“只检查状态”查看哪些已提交、哪些尚未创建。随后选择“仅保存草稿”或“保存并提交”，点击“核对并执行”，核对摘要并勾选确认，再次点击执行。
7. 结果显示在每个日期下方，也可以在“执行记录”中导出不包含工作正文的 JSON 记录。

## 已有记录如何处理

- 已提交、已锁定：始终跳过，不撤回、不发起修改。
- 同项目同日期有多条记录：停止，交由使用者在网站确认。
- 未提交且内容相同：核对后可以直接提交。
- 未提交但内容不同：默认跳过；勾选“允许更新已有的不同草稿”才覆盖。
- 未创建：从网站项目导入窗口选择**唯一一个项目**创建，再正常填写和提交。
- 失败或超时：立即停止，不盲目重试。因为网站可能已写入，先切换“只检查状态”或打开网站记录确认，再决定继续。
- 停止按钮会等待当前这一条结束，避免停在保存与提交之间。

## 工作方式与范围

脚本通过网站现有日期树、项目导入窗口、表单和提交按钮操作；只监听网站自己发出的请求完成结果。不会重放上一位用户的接口参数，不自行拼接 `/common/save` 等业务请求。正常的会话、权限检查和加密仍由网站处理。

项目选择、默认工时、年份和统一标题会记在当前浏览器的本地配置中。工作正文、导入文件、审批人 ID 和执行日志不持久化，也不会上传到其他服务。刷新页面后需要重新导入内容、读取当前账号项目。

处理时请保持网站标签页打开，不要同时手动切换日期、修改表单或在另一标签页运行批处理。支持 Web Locks 的浏览器会阻止同一来源的两个助手同时运行。网站结构变更时会停止并显示错误，需更新脚本适配。

## 验证与维护

开发验证包含日期/Markdown 解析测试、隔离模拟网站的完整流程测试，以及真实网站的项目读取和已提交记录跳过检查。真实网站测试不重新创建或提交已有日报。

`tests/` 为维护者使用的测试文件，不影响普通安装。脚本没有外部依赖、自动更新或联网加载的库。网站如更换域名，应审查后修改脚本头部的 `@match` 和脚本内部的域名检查。

参考：[Tampermonkey 用户脚本元数据文档](https://www.tampermonkey.net/documentation.php)。
